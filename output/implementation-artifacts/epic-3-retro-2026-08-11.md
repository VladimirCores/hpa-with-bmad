## Key Insights

1. Native tool-auth routes (Casdoor/Casbin bypassed) are a deliberate, repeated pattern — but the boundary between "tool UI route" and "platform domain route" is where ambiguity (Epic 10 catch-all) enters.
2. No-fork revalidation (3.9 reusing 1.5) is the correct pattern and should be applied wherever an epic re-encounters an already-implemented requirement.
3. Record drift is bidirectional: untracked implemented work (3-13) is as corrosive to the audit trail as missing records (4-3..4-10, 5-2).
