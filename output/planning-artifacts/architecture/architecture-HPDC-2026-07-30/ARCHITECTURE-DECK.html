Architecture Decisions

13 binding decisions governing all implementation.

AD-1

Envoy Gateway as exclusive ingress boundary

Every external route declared as K8s Gateway API resource. No backend exposes ports externally without a matching route. TLS termination at EG via cert-manager.

FR-36FR-37FR-38
AD-2

Domain-per-route segregation

Each route is its own bounded domain. Domains communicate exclusively through the event-mesh (Pulsar/Kafka) or DB change feeds — never through direct HTTP calls to another domain.

FR-1FR-5FR-36
AD-3

Serverless-first compute

All compute via KNative (scale-to-zero), SpinKube WASM, Pulsar Functions, or Argo Workflows. No Deployment/StatefulSet for application logic.

FR-5FR-6FR-11
AD-4

Event-mesh as the integration fabric

Pulsar = primary backbone (100K+ RPS telemetry). Kafka = secondary (alert signals, external events). DB change feeds trigger KNative Eventing.

FR-1FR-2FR-3
AD-5

Protobuf normalized envelope

All messages use Protobuf with Schema Registry. CommonEnvelope: device_id, event_type, timestamp, idempotency_key, origin. Max 64KB, oversized rejected at gateway.

FR-2
AD-6

Database ownership boundaries

Each DB owns specific data (CouchDB → docs, YugabyteDB → txn state, ArcadeDB → graph, ClickHouse → analytics, KeyDB → cache, PostgreSQL → auth). Prevents duplication, not access.

FR-13FR-14
AD-7

Ceph for all persistent state

Every stateful workload uses Ceph RBD PVCs. No hostPath, emptyDir, or local volume for stateful data. CouchDB, YugabyteDB, ClickHouse, KeyDB, ArcadeDB, Pulsar, Kafka, PostgreSQL.

FR-24
AD-8

mTLS for all inter-service communication

All service-to-service traffic uses mTLS enforced by Cilium. SPIFFE/SPIRE certificate lifecycle with auto-rotation.

FR-45
AD-9

GitOps-only delivery

All changes flow through Git → Kargo (Freight) → Argo CD (ApplicationSet with Sync Waves). Direct kubectl forbidden. Monorepo with Kustomize overlays.

FR-17FR-18FR-19
AD-10

Air-gapped delivery

Harbor = local OCI registry, Trivy scanning, Cosign signing. Spegel P2P distribution. Git repos mirrored locally. No internet dependency during deployment.

FR-30FR-31FR-32
AD-11

Multi-region data sovereignty

Each region has independent DB instances. No automatic cross-region replication. Cilium ClusterMesh over WireGuard VPN for cross-region service discovery.

FR-33FR-34FR-35
AD-12

Observability

Structured JSON logs to stdout. OpenTelemetry auto-instrumentation. VictoriaMetrics cluster + Grafana. Hubble network observability. Retention: 7d raw, 30d aggregated, 1y monthly.

FR-25FR-26FR-27
AD-13

Centralized secrets management

Secrets in Infisical, never in git. CSI Driver volume injection. Auto-rotation every 90 days. Per-function service accounts.
